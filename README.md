## Iris Dataset

The Iris dataset contains 150 flower samples and four measurement features:

- Sepal length
- Sepal width
- Petal length
- Petal width

The dataset contains three flower species:

- 50 Setosa flowers
- 50 Versicolor flowers
- 50 Virginica flowers

## Key Findings

The scatter plot comparing sepal length and sepal width showed that Setosa was more clearly separated from the other two species. Versicolor and Virginica had more overlap, which made them harder to distinguish using only sepal measurements.

The species count chart showed that the dataset was balanced because each species had 50 samples. This balance prevents one species from having more examples than the others.
